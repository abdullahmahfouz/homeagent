What the agent actually does.

Live tool calls

Each listing search and mortgage calculation renders as it runs, then flips to a result you can check.

Answers that stream

Tokens arrive as the model writes them. No spinner standing in for progress.

Mortgage math

Conventional US terms, with PMI added automatically when the down payment is under 20 percent.

A map that responds

Price pins for the active result set. Click a pin to focus a listing, or a card to fly the map to it.

Sessions that persist

Conversations are saved to your browser. Come back to a search from last week and pick it up where you stopped.

The payment math, done in the chat.

Ask what a listing costs per month and the agent runs the same conventional calculation a lender would start from, PMI included.

Questions.

Where do the listings come from?

Live US MLS data through the Repliers API. Results reflect the current active set rather than a cached snapshot.

Is the mortgage estimate accurate?

It uses standard US conventional terms, including PMI above 80 percent LTV. Treat it as an estimate rather than a quote. Taxes, insurance, and rates vary by county and lender.

Which model runs the agent?

Gemini 2.5 Flash with function calling. The agent loop itself is roughly eighty lines of Python.

Do I need an account?

No. Open the app and start typing. Sessions are stored in your browser, so nothing is tied to a login.
